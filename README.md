# Running of application

### Known minimum required versions

**Node.js:** 22.18.0

### How to run

For this application, navigate to /QuizApp, and execute 
```
npm run build
npm run preview
```
in the terminal to run the project.

### Test Suite

There exists a test suite for the backend/server-side. To run the complete suite, navigate to /api.tests, and execute 
```
dotnet test
```
to run all tests.
